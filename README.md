# Todo App

This repository contains the NestJS API and React frontend as separate applications.

## API

```bash
cd api
npm install
npm run start:dev
```

The API runs at `http://localhost:3000`.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend runs at `http://localhost:5173` and connects to the API at `http://localhost:3000/api` by default.
